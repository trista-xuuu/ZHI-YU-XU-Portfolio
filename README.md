# ZHI YU XU Portfolio

徐芝瑜的網站企劃、UIUX 設計與專案作品集。

## 技術

- Next.js App Router
- TypeScript
- CSS
- Vercel

## 本機執行

```bash
npm install
npm run dev
```

## 正式建置

```bash
npm run lint
npm run build
```

## 環境變數

正式部署時設定：

```text
NEXT_PUBLIC_SITE_URL=https://你的正式網域
```

此變數用於 canonical URL、Open Graph、robots.txt 與 sitemap.xml。
